# Hotbar Scale — Minecraft 1.21.11 Fabric

Мод клиентский. При первом запуске создаёт `config/hotbar-scale.json`.

Пример:
```json
{
  "scale": 1.5
}
```

Допустимый диапазон: `0.5`–`3.0`; `1.0` — исходный масштаб. После изменения перезапустите игру.

## Сборка с телефона без установки Java/Gradle
1. Создайте репозиторий GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** и запустите workflow **Build Hotbar Scale** (Run workflow).
3. После завершения откройте запуск workflow и скачайте артефакт `hotbar-scale-mod`.
4. Распакуйте архив артефакта и поместите файл `.jar` в папку `mods` Zalith Launcher.

Важно: сборка зависит от доступности указанных версий Minecraft/Fabric/Yarn. Проект подготовлен, но в этой среде не был собран и протестирован.
